# Task Manager

Web application for managing tasks, made with HTML, CSS, and JavaScript. This project uses PostgreSQL database and REST API hosted on Supabase, and is deployed on GitHub Pages.

---

## Features
* **Display Tasks:** Fetch and display all tasks dynamically from the Supabase database.
* **Create Task:** Add new tasks with titles and descriptions.
* **Edit Task:** Edit existing task.
* **Toggle Status:** Mark tasks as completed or incomplete.
* **Delete Task:** Remove tasks from the database.

## Technologies Used
* **Frontend:** HTML, CSS, JavaScript
* **Database & REST API:** [Supabase](https://supabase.com/)
* **Version Control:** Git, GitHub and GitHub Pages
